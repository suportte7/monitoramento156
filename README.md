# Dashboard 156 EMLURB - Monitoramento

Painel analítico, interativo e PWA (Progressive Web App) desenvolvido para o monitoramento de demandas e KPIs da EMLURB (Autarquia de Manutenção e Limpeza Urbana / SGDEM 156).

## 🚀 Recursos
- **Processamento Local:** Leitura de planilhas `.xlsx` e `.xls` de forma instantânea sem envio de dados para servidores externos.
- **PWA (Instalável):** O painel pode ser instalado como um aplicativo nativo em telemóveis Android e iOS.
- **Filtros e KPIs Avançados:** Cálculo automático de prazos, atrasos e índices (IC %, IE % e IA %).
- **Exportação Inteligente:** Geração de relatórios em PDF e Excel que respeitam a visibilidade das colunas definidas pelo utilizador.
- **Gráficos Dinâmicos:** Integração com Chart.js para visualização de filas, tendências temporais e curva de Pareto.

## 📌 Acesso
Para utilizar, basta aceder à página gerada pelo GitHub Pages deste repositório e selecionar o ficheiro da Base DVCC.
